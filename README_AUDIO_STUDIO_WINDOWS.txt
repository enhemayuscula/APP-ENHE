AUDIO STUDIO WINDOWS · Ñ Mayúscula

Uso recomendado:

1. Instalar AudioStudio_Setup.exe una vez.
2. Abrir la pestaña Audio Studio de la app.
3. Pulsar “Abrir Audio Studio”.
4. Windows abrirá el protocolo audiostudio:// y arrancará el motor local.
5. Separar el audio.
6. Trabajar en la sesión multipista: Play común, Mute, Solo, volumen, velocidad, loop, tono y exportación de mezcla.

Ubicación del instalador dentro de esta app:

assets/audio-studio/AudioStudio_Setup.exe

El ZIP de pistas queda como opción secundaria, no como flujo principal.
