Ñ Mayúscula · Biblioteca de pistas

Esta versión añade un reproductor de pistas ya separadas dentro de la app.

Uso:
1. Audio Studio Admin v3 separa el tema en Windows.
2. Exporta el paquete para biblioteca Drive.
3. Actualiza el archivo assets/audio-library/library_n_mayuscula.json.
4. Los músicos abren la app y entran en “Pistas”.

Importante:
- Esta app NO separa audio.
- Esta app solo reproduce pistas ya preparadas.
- El tono solo funciona si el índice incluye variantes de tono generadas previamente.
- La biblioteca de Ñ Mayúscula no debe mezclarse con la de la otra banda.
